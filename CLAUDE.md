# Engineering Docs — CLAUDE.md

## Project Overview

Docusaurus 3 static site serving as the internal engineering documentation for Voynich Services. Deployed to GitHub Pages at `https://voynich-services.github.io/engineering-docs/`. Documents the FARM stack onboarding process and an Automation Challenge for interns.

## Commands

```bash
yarn           # install dependencies
yarn start     # local dev server (localhost:3000) with hot-reload
yarn build     # generate static site into build/
yarn serve     # serve built output locally
yarn typecheck # TypeScript type check (only QA step — no tests)
yarn deploy    # build + push to gh-pages branch
yarn clear     # clear Docusaurus cache (use when builds behave strangely)
```

Primary package manager is **Yarn** (also has a `package-lock.json` but yarn.lock is authoritative).

## Architecture

```
docs/
  onboarding/           # 6-page intern onboarding sequence
  automation-challenge/ # 2-page intern Python challenge
src/
  pages/index.tsx       # Custom homepage (hero + CTA)
  css/custom.css        # Brand color overrides (green palette)
  components/HomepageFeatures/  # Boilerplate feature cards (unused)
static/img/             # Logos, favicon, social card
docusaurus.config.ts    # Active config (TS version supersedes .js)
sidebars.ts             # Auto-generated sidebar from docs/ filesystem
```

## Key Rules

- **Active config is `docusaurus.config.ts`** — the `.js` version is stale (references old doc IDs, old sidebar, no faster/v4 flags). Do not edit the `.js` file.
- **Active sidebar is `sidebars.ts`** — uses `autogenerated` from `docs/`. The `.js` sidebar is stale and has a broken doc ID (`onboarding/04-Quick-Fixes` which no longer exists).
- `onBrokenLinks: 'throw'` is set — a broken link in any `.md` file will fail the build.
- `@docusaurus/faster` (Rspack/SWC) is enabled for faster builds.
- No test suite. `yarn typecheck` is the only automated check.

## Content Structure

- `docs/onboarding/` — pages numbered `01-` through `06-`; sidebar order follows filename prefix.
- `docs/automation-challenge/` — pages numbered `01-` and `02-`
- Each section has a `_category_.json` that controls the sidebar label and position.
- To add a new section: create a new folder under `docs/`, add `_category_.json`, and add numbered `.md` files.

## Deployment

```bash
yarn deploy                  # uses GIT_USER=voynich-services (hardcoded in package.json)
USE_SSH=true yarn deploy     # SSH-based alternative
```

Pushes to the `gh-pages` branch of `voynich-services/engineering-docs`.
